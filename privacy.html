Privacy policy

Last updated November 23, 2026

family-automation is a set of personal projects used by a single household for itself. It is not a commercial service and has no users outside that household. This policy covers each project and the Google data it uses.

Nest thermostats

With the household's authorization, the app uses the Google Smart Device Management API to read and change the household's own Nest thermostats. This includes indoor temperature, humidity, heating and cooling status, setpoints, and thermostat mode.

The app also records whether household members' phones are on the home Wi-Fi network, and receives arrive/leave events that household members choose to send from their own phones. It also records comfort feedback ("too warm", "too cold", "fine") that household members submit.

This data is used only to choose thermostat setpoints and to measure how well the app saves energy. Summaries of thermostat state, the weather forecast and comfort feedback are sent to the Anthropic API to help plan setpoints. Weather forecasts are fetched from Open-Meteo, and no household data is sent to Open-Meteo.

Backups to Google Drive

The thermostat project's data is encrypted on the home computer and then uploaded to the household's own Google Drive. The app uses only Drive access to the files it creates itself (the drive.file permission); it cannot see or change any other Drive files. Google cannot read the backups' contents, because they are encrypted before upload.

Gmail cleanup

With the household's authorization, the app uses the Gmail API to manage the household's own mailbox. It searches for messages that match the household's rules and reads their metadata: sender, subject, date, labels and the unsubscribe header. It does not read message bodies or attachments. It then adds labels, archives, marks as read, or moves matching messages to Trash. It cannot permanently delete mail, and it never sends email.

Gmail data is used only to apply those rules and to show the household what a run would change. It is not sent to any other service. The app keeps a log on the home computer of what each run changed (message and label identifiers only), so that a run can be undone, and run reports listing the affected messages' senders and subjects.

Storage and sharing

Data is stored on a computer inside the home, plus the encrypted backups in the household's own Google Drive. It is not sold, not used for advertising, not used to train AI models, and not shared with anyone except the services named above, which the apps need in order to work.

Retention and deletion

The household can delete the stored data at any time. Google access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions) or, for the thermostats, the Nest partner connections page (nestservices.google.com/partnerconnections).

Google API Services User Data Policy

The apps' use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
